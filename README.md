## 🛠️ Technology Stack

* **Frontend**: React 19, TypeScript
* **Build Tool**: Vite
* **Styling**: Tailwind CSS
* **Animations**: Framer Motion
* **Icons**: Lucide React
* **Routing**: React Router DOM (v7)
* **SEO**: Structured Schema.org (JSON-LD), OpenGraph, Twitter Cards, Local Geo-Tags for Kota, Rajasthan

## 🚀 Getting Started

### Prerequisites
* Node.js (v18 or higher recommended)
* npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Mahaveer555/Deeppura-builders.git

# Navigate to project folder
cd Deeppura-builders

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
